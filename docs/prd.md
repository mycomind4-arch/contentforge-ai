# Product Requirements Draft

## Product Goal

Build a GitHub-first AI content platform that supports planning, writing, research, image generation, SEO optimization, and publishing in one workflow.

## Primary Users

- Content marketers
- Editorial teams
- Solo operators
- Agencies

## Core Jobs To Be Done

- Create content faster
- Keep brand voice consistent
- Support research-backed writing
- Manage content projects at scale
- Export and publish to external platforms

## MVP Scope

- Authentication
- Project management
- Rich text editor
- AI writing assistance
- Image generation
- Export flow
- Dashboard

## Out of Scope For MVP

- Multi-user collaboration
- Marketplace
- Advanced analytics
- Full automation graph
- Broad third-party publishing support
